# Library App

A small web app to manage a personal book library. Built as a project for The Odin Project JavaScript curriculum.

## Features

- Add books with title, author, pages, and read status via a modal form.
- Display books as stylish cards with unique IDs.
- Toggle read status and remove books with dedicated buttons.
- Data stored in an array to separate data logic and UI.

## Technologies

- HTML5 & CSS3 (Flexbox/Grid & modern styling)
- JavaScript (ES6+, DOM manipulation)
- Uses `crypto.randomUUID()` for unique book IDs.

## Usage

Open `index.html` in a modern browser. Click **New Book** to add entries and manage your library interactively.
